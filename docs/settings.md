# Einstellungen

## Dimensionen (rechts, Reiter „Dimensionen“)

| Einstellung | Beschreibung |
| --- | --- |
| Name | Steht in der ersten Spalte. Pflicht. |
| Typ | **Text** (freier Text, Zeilenumbrüche bleiben), **Zahl** (mit Einheit, auf Wunsch Bestwert), **Ja/Nein** (Haken oder Kreuz), **Liste** (je Zeile ein Eintrag, als Aufzählung), **Auswahl** (ein Wert aus festen Optionen), **Bewertung** (1–5 Sterne), **Galerie** (Bilder zum Blättern und Vergrößern, vergleicht nichts). Vorgabe: Text. |
| Erläuterung | Optional, steht klein unter dem Namen. |
| Einheiten | Nur bei Zahl. Eine oder mehrere Einheiten, z. B. „PS“ und „kW“; die Einheit steht hinter jeder Zahl. Bei mehreren Einheiten bekommt jedes Element je Einheit ein eigenes Feld, auf der Seite steht je Einheit eine Zeile. Der Bestwert vergleicht die erste Einheit. |
| Bestwert | Nur bei Zahl: **Neutral** (keine Markierung), **Höher ist besser** oder **Niedriger ist besser**. Vorgabe: Neutral. Bewertungen gelten immer als „höher ist besser“. |
| Optionen | Nur bei Auswahl. Die Werte, aus denen jedes Element einen wählt. Mindestens eine. |
| Icon vor dem Namen | Optional, ein Icon aus der Icon-Bibliothek vor dem Namen der Dimension. |
| Zeichen für Ja / Nein | Nur bei Ja/Nein. Icon aus der Icon-Bibliothek; Vorgabe Haken und Kreuz. |
| Farbe für Ja / Nein | Nur bei Ja/Nein. Eine MAN-CI-, Status- oder eigene Farbe; Vorgabe Akzentfarbe für Ja und Grau für Nein. Eine gewählte Farbe bleibt auch in abgeblendeten Zeilen stehen. |
| Größe der Zeichen | Nur bei Ja/Nein. **Kleiner** (8 × 8 px), **Normal** (10 × 10 px) oder **Größer** (12 × 12 px). Vorgabe: Normal. |

Unter jeder aufgeklappten Dimension: nach oben/unten schieben, **duplizieren** (die Kopie übernimmt Typ, Einstellungen und alle Werte und steht direkt dahinter) und löschen.

## Elemente (links und Mitte)

| Einstellung | Beschreibung |
| --- | --- |
| Name | Steht über der Spalte. Pflicht. |
| Untertitel | Optional, eine Zeile unter dem Namen. |
| Werte | Je Dimension ein Feld passend zum Typ. Leer heißt „keine Angabe“ und erscheint als „–“. Auf der Seite stehen die Werte mittig in ihrer Spalte. |

Elemente und Dimensionen gibt es beliebig viele, Bilder höchstens 20 je Galerie. Bilder einer Galerie werden nie beschnitten: Die Höhe der Galerie-Zeile richtet sich nach dem höchsten Bild aller Elemente.

## Gestaltung (rechts, Reiter „Gestaltung“)

| Einstellung | Beschreibung |
| --- | --- |
| Überschrift | Optional, steht über der Tabelle. |
| Akzent | **Rot**, **Anthrazit** oder **Blau** – Farbe der Haken, Sterne, Icons und Bestwerte. Vorgabe: Rot. |
| Transponieren | Kehrt die Tabelle um: Elemente als Zeilen (Name links, bleibt beim Scrollen stehen), Dimensionen als Spalten. Abblenden, Bestwerte, „Nur Unterschiede“ und „Sichtbare Zeilen“ gelten weiter – eingeklappt werden dann Elemente. Vorgabe: aus. |
| Gleiche Werte abblenden | Dimensionen, in denen alle Elemente denselben Wert haben, werden grau. „Keine Angabe“ zählt als eigener Wert. Galerien werden nie abgeblendet. Vorgabe: an. |
| Bestwerte markieren | Hebt bei Zahlen mit Vorzug und bei Bewertungen den besten Wert hervor. Haben alle Elemente denselben Wert, wird nichts markiert. Vorgabe: an. |

## Verhalten (rechts, Reiter „Verhalten“)

| Einstellung | Beschreibung |
| --- | --- |
| Sichtbare Zeilen | Wie viele Zeilen (Dimensionen) zu sehen sind; der Rest klappt hinter den Knopf „Weitere … Zeilen einblenden“ ein. **0** zeigt alle. Vorgabe: 5. |
| Schalter „Nur Unterschiede“ | Zeigt Leser:innen über der Tabelle einen Schalter, der Zeilen ohne Unterschied ausblendet. Die Wahl wird nicht gespeichert. Vorgabe: aus. |
