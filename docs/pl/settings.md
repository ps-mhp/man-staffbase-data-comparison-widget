# Ustawienia

## Wymiary (po prawej stronie, zakładka „Wymiary”)

| Ustawienie | Opis |
| --- | --- |
| Nazwa | Znajduje się w pierwszej kolumnie. Pole obowiązkowe. |
| Typ | **Tekst** (tekst dowolny, zachowuje znaki końca linii), **Liczba** (z jednostką, opcjonalnie wartość maksymalna), **Tak/Nie** (haczyk lub krzyżyk), **Lista** (jedna pozycja w każdym wierszu, w formie wypunktowania), **Wybór** (jedna wartość spośród stałych opcji), **Ocena** (1–5 gwiazdek), **Galeria** (zdjęcia do przeglądania i powiększania, nie porównuje niczego). Ustawienie domyślne: Tekst. |
| Objaśnienie | Opcjonalne, umieszczone małą czcionką pod nazwą. |
| Jednostka | Tylko w przypadku liczby. Umieszczona za każdą liczbą, np. „PS” lub „%”. |
| Najlepsza wartość | Tylko w przypadku liczby: **Neutralna** (brak oznaczenia), **Im wyższa, tym lepsza** lub **Im niższa, tym lepsza**. Domyślnie: neutralna. Oceny zawsze traktowane są jako „im wyższa, tym lepsza”. |
| Opcje | Tylko w przypadku wyboru. Wartości, spośród których każdy element wybiera jedną. Co najmniej jedna. |

## Elementy (po lewej i pośrodku)

| Ustawienie | Opis |
| --- | --- |
| Nazwa | Znajduje się nad kolumną. Obowiązkowe. |
| Podtytuł | Opcjonalne, wiersz poniżej nazwy. |
| Wartości | Jedno pole na każdy wymiar, dostosowane do typu. Puste pole oznacza „brak danych” i wyświetla się jako „–”. |

Maksymalnie 12 elementów, 60 wymiarów i 20 obrazów na galerię.

## Układ (po prawej, zakładka „Układ”)

| Ustawienie | Opis |
| --- | --- |
| Nagłówek | Opcjonalny, znajduje się nad tabelą. |
| Akcent | **Czerwony**, **antracytowy** lub **niebieski** – kolor linii nad tabelą, haczyków, gwiazdek i najlepszych wyników. Ustawienie domyślne: czerwony. |
| Ukryj identyczne wiersze | Wiersze, w których wszystkie elementy mają tę samą wartość, stają się szare. „Brak danych” liczy się jako osobna wartość. Galerie nigdy nie są ukrywane. Ustawienie domyślne: włączone. |
| Zaznaczaj najlepsze wartości | Podkreśla najlepszą wartość w przypadku liczb z preferencjami oraz ocen. Jeśli wszystkie elementy mają tę samą wartość, nic nie jest zaznaczane. Ustawienie domyślne: włączone. |

## Zachowanie (po prawej stronie, zakładka „Zachowanie”)

| Ustawienie | Opis |
| --- | --- |
| Przełącznik „Tylko różnice” | Wyświetla czytelnikom nad tabelą przełącznik, który ukrywa wiersze bez różnic. Wybór nie jest zapisywany. Ustawienie domyślne: wyłączone. |
