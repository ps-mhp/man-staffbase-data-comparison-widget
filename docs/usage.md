# Schritt für Schritt

## Grundfall einrichten

1. Ziehen Sie das Widget **Datenvergleich** an die gewünschte Stelle der Seite. Es braucht die volle Breite des Inhaltsbereichs am besten – in schmalen Spalten muss früher gescrollt werden.
2. Öffnen Sie die Einstellungen des Widgets. Es öffnet sich das Fenster **Vergleich bearbeiten**.
3. Rechts unter **Dimensionen**: Klicken Sie auf **Neue Dimension**, geben Sie einen **Namen** ein (z. B. „Leistung“) und wählen Sie den **Typ** (z. B. „Zahl“). Bei Zahlen tragen Sie die **Einheit** ein (z. B. „PS“) und legen unter **Bestwert** fest, ob höhere oder niedrigere Werte besser sind.
4. Wiederholen Sie Schritt 3 für jedes Merkmal. Die Reihenfolge rechts ist die Reihenfolge der Zeilen; ändern lässt sie sich mit den Pfeilen unter jeder aufgeklappten Dimension.
5. Links unter **Elemente**: Klicken Sie auf **Neues Element** und geben Sie in der Mitte den **Namen** ein (er steht über der Spalte), optional einen **Untertitel**.
6. Tragen Sie in der Mitte unter **Werte** für jede Dimension den Wert dieses Elements ein. Felder, die Sie leer lassen, erscheinen auf der Seite als „–“.
7. Legen Sie die weiteren Elemente genauso an. Die Reihenfolge links ist die Reihenfolge der Spalten; ziehen Sie ein Element am Griff an eine andere Stelle.
8. Prüfen Sie das Ergebnis über **Desktop** und **Mobil** oben im Fenster und klicken Sie auf **Übernehmen**. Speichern bzw. veröffentlichen Sie anschließend die Seite.

## Bilder hinzufügen (Galerie)

1. Legen Sie rechts eine Dimension mit dem Typ **Galerie** an, z. B. „Ansichten“. Am besten schieben Sie sie ganz nach oben.
2. Wählen Sie links ein Element. In der Mitte erscheint bei der Galerie der Knopf **Bild hinzufügen**.
3. Klicken Sie darauf und wählen Sie ein Bild aus der Mediathek – oder ziehen Sie ein Bild aus der geöffneten Mediathek-Leiste auf das Feld.
4. Tragen Sie für jedes Bild eine **Bildbeschreibung** ein; sie wird vorgelesen und in der Vergrößerung als Bildunterschrift gezeigt.
5. Ändern Sie die Reihenfolge der Bilder mit den Pfeilen, entfernen Sie Bilder mit dem Papierkorb.

## Nachträglich ändern

1. Öffnen Sie die Einstellungen des Widgets erneut.
2. Um eine Dimension zu ändern, klappen Sie sie rechts auf. Wenn Sie den **Typ** wechseln, werden vorhandene Werte übernommen, soweit es geht (z. B. Text ↔ Liste, Text → Auswahl). Was nicht passt, entfällt – mit **Rückgängig** holen Sie es zurück.
3. Wenn Sie eine Dimension löschen, verschwinden ihre Werte bei allen Elementen.
4. Klicken Sie auf **Übernehmen** und speichern Sie die Seite.

## Wenn etwas nicht funktioniert

1. **Übernehmen** ist nicht möglich und nennt Fehler: Jedes Element und jede Dimension braucht einen Namen, jede Auswahl mindestens eine benannte Option. Die betroffenen Einträge sind rot markiert.
2. Die Tabelle erscheint nicht auf der Seite: Es braucht mindestens ein Element und eine Dimension mit mindestens einem Wert.
3. Erscheint statt des Bearbeitungsfensters nur ein Textfeld, laden Sie das Studio neu. Das Textfeld enthält den Vergleich als Text – ändern Sie es nur, wenn Sie wissen, was Sie tun.
