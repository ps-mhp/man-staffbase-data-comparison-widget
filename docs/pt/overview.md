# Comparação de dados

A comparação de dados coloca vários elementos — como modelos de veículos, versões de equipamento ou ofertas — lado a lado e compara-os com base num conjunto de características. Basta definir uma vez **o que** será comparado (as dimensões) e, em seguida, introduzir os valores de cada elemento.

Cada dimensão tem um tipo: texto, número com unidade, Sim/Não, lista, seleção entre opções fixas, avaliação com estrelas ou galeria. O tipo determina como o valor é introduzido e apresentado.

## O que os leitores vêem

Uma tabela: Na primeira coluna encontram-se as dimensões; ao lado de cada elemento, há uma coluna com o nome e um subtítulo opcional. Quando há muitos elementos, é possível percorrer a tabela horizontalmente; a primeira coluna permanece fixa.

- As linhas em que todos os elementos são iguais ficam em cinzento – as diferenças destacam-se.
- No caso de números com preferência («Quanto mais alto, melhor» ou «Quanto mais baixo, melhor») e de avaliações, o melhor valor é destacado a cores e assinalado como «Melhor valor».
- Uma **galeria** apresenta uma ou mais imagens por elemento. Os leitores podem percorrer a galeria com as setas; o botão no canto superior direito amplia a imagem para ocupar todo o ecrã. A galeria não faz comparações.
- Se desejar, existe acima da tabela o botão **Apenas diferenças**, que oculta as linhas idênticas.

## O que vê no editor do CMS

A caixa de diálogo de configuração abre uma grande janela de edição: à esquerda, os elementos; no centro, os valores do elemento selecionado; à direita, as dimensões, bem como o design e o comportamento. Através das opções **Desktop**, **Tablet** e **Móvel**, na parte superior da janela, pode ver a tabela tal como aparece na página.
