# Definições

## Dimensões (à direita, separador «Dimensões»)

| Definição | Descrição |
| --- | --- |
| Nome | Aparece na primeira coluna. Obrigatório. |
| Tipo | **Texto** (texto livre, mantém as quebras de linha), **Número** (com unidade, valor máximo opcional), **Sim/Não** (caixa de seleção ou cruz), **Lista** (uma entrada por linha, como enumeração), **Seleção** (um valor entre opções fixas), **Avaliação** (1–5 estrelas), **Galeria** (imagens para percorrer e ampliar, não compara nada). Predefinição: Texto. |
| Explicação | Opcional, aparece em letras pequenas abaixo do nome. |
| Unidade | Apenas para números. Aparece após cada número, por exemplo, «PS» ou «%». |
| Valor padrão | Apenas para números: **Neutro** (sem marcação), **Quanto mais alto, melhor** ou **Quanto mais baixo, melhor**. Padrão: Neutro. As avaliações são sempre consideradas como «quanto mais alto, melhor». |
| Opções | Apenas para seleção. Os valores entre os quais cada elemento escolhe um. Pelo menos um. |

## Elementos (à esquerda e ao centro)

| Configuração | Descrição |
| --- | --- |
| Nome | Aparece acima da coluna. Obrigatório. |
| Subtítulo | Opcional, uma linha abaixo do nome. |
| Valores | Um campo por dimensão, adequado ao tipo. Em branco significa «sem indicação» e aparece como «–». |

Máximo de 12 elementos, 60 dimensões e 20 imagens por galeria.

## Design (à direita, separador «Design»)

| Configuração | Descrição |
| --- | --- |
| Título | Opcional, aparece acima da tabela. |
| Destaque | **Vermelho**, **antracite** ou **azul** – cor da linha acima da tabela, das marcas de verificação, das estrelas e dos melhores valores. Predefinição: Vermelho. |
| Ocultar linhas iguais | As linhas em que todos os elementos têm o mesmo valor ficam a cinzento. «Sem indicação» conta como um valor próprio. As galerias nunca são ocultadas. Predefinição: ativado. |
| Destacar os melhores valores | Destaca o melhor valor em números com preferência e em avaliações. Se todos os elementos tiverem o mesmo valor, nada é destacado. Predefinição: ativado. |

## Comportamento (à direita, separador «Comportamento»)

| Configuração | Descrição |
| --- | --- |
| Botão «Apenas diferenças» | Mostra aos leitores, acima da tabela, um botão que oculta as linhas sem diferenças. A escolha não é guardada. Predefinição: desativado. |
