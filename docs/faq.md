# FAQ

**Frage:** „Element 1: Name fehlt“ – was muss ich tun?

Antwort: Jedes Element braucht einen Namen, weil er über seiner Spalte steht. Wählen Sie das Element links und tragen Sie in der Mitte unter **Name** etwas ein.

**Frage:** „Dimension 2: Name fehlt“ – was muss ich tun?

Antwort: Klappen Sie rechts unter **Dimensionen** die genannte Dimension auf und tragen Sie einen **Namen** ein.

**Frage:** „Dimension 3: Auswahl ohne Optionen“ oder „Option ohne Namen“ – was heißt das?

Antwort: Eine Dimension vom Typ **Auswahl** braucht mindestens eine benannte Option. Klappen Sie die Dimension auf und legen Sie über **Option hinzufügen** Optionen an, oder entfernen Sie leere Optionen.

**Frage:** Warum steht im Editor „Keine Zahl – gespeichert bleibt der letzte gültige Wert.“?

Antwort: Im Zahlenfeld steht etwas, das keine Zahl ist. Erlaubt sind Ziffern, ein Komma oder Punkt als Dezimalzeichen und ein Minus. Die Einheit tragen Sie bei der Dimension ein, nicht im Wert.

**Frage:** Warum ist eine Zeile grau?

Antwort: Alle Elemente haben dort denselben Wert. Das lässt sich unter **Gestaltung → Gleiche Zeilen abblenden** abschalten.

**Frage:** Warum ist kein Bestwert markiert?

Antwort: Bestwerte gibt es nur bei Zahlen mit **Bestwert** „Höher ist besser“ oder „Niedriger ist besser“ und bei Bewertungen – und nur, wenn mindestens zwei Elemente einen Wert haben und nicht alle gleich sind. Außerdem muss **Gestaltung → Bestwerte markieren** an sein.

**Frage:** Eine Dimension erscheint nicht auf der Seite.

Antwort: Zeilen, in denen kein Element einen Wert hat, werden ausgeblendet. Tragen Sie mindestens bei einem Element einen Wert ein.

**Frage:** Ich habe den Typ einer Dimension gewechselt und Werte sind weg.

Antwort: Beim Wechsel werden Werte übernommen, soweit es geht. Was nicht passt (z. B. Text → Ja/Nein, wenn der Text weder „Ja“ noch „Nein“ ist, oder alles von und zu Galerie), entfällt. Klicken Sie auf **Rückgängig**, solange Sie das Fenster noch nicht geschlossen haben.
