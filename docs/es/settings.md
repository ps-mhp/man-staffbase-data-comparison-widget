# Configuración

## Dimensiones (a la derecha, pestaña «Dimensiones»)

| Configuración | Descripción |
| --- | --- |
| Nombre | Aparece en la primera columna. Obligatorio. |
| Tipo | **Texto** (texto libre, se conservan los saltos de línea), **Número** (con unidad, valor máximo si se desea), **Sí/No** (marca de verificación o cruz), **Lista** (una entrada por línea, en forma de enumeración), **Selección** (un valor de entre opciones fijas), **Valoración** (1-5 estrellas), **Galería** (imágenes para hojear y ampliar, no compara nada). Por defecto: Texto. |
| Explicación | Opcional, aparece en letra pequeña debajo del nombre. |
| Unidad | Solo para números. Aparece detrás de cada número, p. ej., «CV» o «%». |
| Valor predeterminado | Solo para números: **Neutral** (sin marcar), **Cuanto más alto, mejor** o **Cuanto más bajo, mejor**. Por defecto: Neutral. Las valoraciones siempre se interpretan como «cuanto más alto, mejor». |
| Opciones | Solo para elementos de selección. Los valores entre los que cada elemento permite elegir uno. Al menos uno. |

## Elementos (izquierda y centro)

| Configuración | Descripción |
| --- | --- |
| Nombre | Aparece encima de la columna. Obligatorio. |
| Subtítulo | Opcional, una línea debajo del nombre. |
| Valores | Un campo por dimensión, adecuado al tipo. Si está en blanco, significa «sin especificar» y aparece como «–». |

Máximo 12 elementos, 60 dimensiones y 20 imágenes por galería.

## Diseño (a la derecha, pestaña «Diseño»)

| Configuración | Descripción |
| --- | --- |
| Encabezado | Opcional, aparece encima de la tabla. |
| Acentuado | **Rojo**, **antracita** o **azul**: color de la línea que recorre la tabla, las marcas de verificación, las estrellas y los mejores valores. Predeterminado: rojo. |
| Ocultar filas iguales | Las filas en las que todos los elementos tienen el mismo valor se muestran en gris. «Sin especificar» cuenta como un valor propio. Las galerías nunca se ocultan. Predeterminado: activado. |
| Resaltar los mejores valores | Resalta el mejor valor en el caso de cifras con preferencia y en las valoraciones. Si todos los elementos tienen el mismo valor, no se resalta nada. Por defecto: activado. |

## Comportamiento (a la derecha, pestaña «Comportamiento»)

| Configuración | Descripción |
| --- | --- |
| Botón «Solo diferencias» | Muestra a los lectores, encima de la tabla, un botón que oculta las filas sin diferencias. La selección no se guarda. Predeterminado: desactivado. |
