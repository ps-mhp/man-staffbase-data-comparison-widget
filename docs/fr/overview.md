# Comparaison de données

La comparaison de données met en parallèle plusieurs éléments – tels que des modèles de véhicules, des niveaux d’équipement ou des offres – et les compare à l’aide d’un ensemble de caractéristiques. Vous définissez une seule fois **ce qui** doit être comparé (les dimensions), puis vous saisissez les valeurs de chaque élément.

Chaque dimension possède un type : texte, nombre avec unité, oui/non, liste, sélection parmi des options fixes, évaluation par étoiles ou galerie. Le type détermine la manière dont la valeur est saisie et affichée.

## Ce que voient les lecteurs et lectrices

Un tableau : La première colonne contient les dimensions, suivies pour chaque élément d’une colonne avec le nom et un sous-titre facultatif. Lorsque le nombre d’éléments est important, le tableau peut être défilé horizontalement ; la première colonne reste alors fixe.

- Les lignes dans lesquelles tous les éléments sont identiques sont grises – les différences ressortent ainsi.
- Pour les chiffres avec une préférence (« Plus c’est élevé, mieux c’est » ou « Plus c’est bas, mieux c’est ») et pour les évaluations, la meilleure valeur est surlignée en couleur et marquée comme « Meilleure valeur ».
- Une **galerie** affiche une ou plusieurs images par élément. Les flèches permettent aux lecteurs de faire défiler les images ; le bouton en haut à droite agrandit l’image en plein écran. La galerie ne compare rien.
- Si vous le souhaitez, le bouton **« Différences uniquement »** situé au-dessus du tableau permet de masquer les lignes identiques.

## Ce que vous voyez dans l’éditeur CMS

La boîte de dialogue de configuration ouvre une grande fenêtre d’édition : à gauche, les éléments ; au centre, les valeurs de l’élément sélectionné ; à droite, les dimensions ainsi que la mise en page et le comportement. Grâce aux onglets **Ordinateur de bureau**, **Tablette** et **Mobile** en haut de la fenêtre, vous pouvez voir le tableau tel qu’il apparaîtra sur la page.
