# Step by Step

## Setting Up the Basic Case

1. Drag the **Data Comparison** widget to the desired location on the page. It works best when it spans the full width of the content area—in narrow columns, users will have to scroll earlier.
2. Open the widget’s settings. The **Edit Comparison** window will open.
3. On the right, under **Dimensions**: Click **New Dimension**, enter a **Name** (e.g., “Performance”), and select the **Type** (e.g., “Number”). For numbers, enter the **unit** (e.g., “PS”) and specify under **Best Value** whether higher or lower values are better.
4. Repeat step 3 for each attribute. The order on the right corresponds to the order of the rows; you can change it using the arrows below each expanded dimension.
5. On the left under **Elements**: Click **New Element** and enter the **Name** in the middle (it appears above the column), and optionally a **Subtitle**.
6. In the center, under **Values**, enter the value for this element for each dimension. Fields you leave blank will appear as “–” on the page.
7. Create the remaining elements in the same way. The order on the left corresponds to the order of the columns; drag an element by its handle to reposition it.
8. Review the result using **Desktop** and **Mobile** at the top of the window, then click **Apply**. Finally, save or publish the page.

## Adding Images (Gallery)

1. Create a dimension on the right with the type **Gallery**, e.g., “Views.” It’s best to move it all the way to the top.
2. Select an element on the left. The **Add Image** button will appear in the center of the gallery.
3. Click it and select an image from the media library—or drag an image from the open media library bar onto the field.
4. Enter an **image description** for each image; it will be read aloud and displayed as a caption when the image is enlarged.
5. Change the order of the images using the arrows; remove images using the trash can icon.

## Making Changes Later

1. Open the widget’s settings again.
2. To change a dimension, expand it on the right. If you change the **Type**, existing values will be carried over as much as possible (e.g., Text ↔ List, Text → Selection). Anything that doesn’t fit is omitted—use **Undo** to restore it.
3. If you delete a dimension, its values will disappear from all elements.
4. Click **Apply** and save the page.

## If Something Doesn’t Work

1. **Apply** is unavailable and displays an error: Every element and every dimension must have a name, and every selection must have at least one named option. The affected entries are highlighted in red.
2. The table does not appear on the page: You need at least one element and one dimension with at least one value.
3. If only a text field appears instead of the editing window, reload Studio. The text field contains the comparison as text—only change it if you know what you’re doing.
