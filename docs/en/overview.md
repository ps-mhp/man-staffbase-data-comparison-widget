# Data Comparison

The data comparison feature displays multiple items—such as vehicle models, trim levels, or offers—side by side and compares them based on a set of characteristics. You first specify **what** is being compared (the dimensions), and then enter the values for each item.

Each dimension has a type: text, number with unit, yes/no, list, selection from fixed options, star rating, or gallery. The type determines how the value is entered and displayed.

## What Readers See

A table: The first column lists the dimensions, with a column next to it for each element containing the name and an optional subtitle. If there are many elements, the table can be scrolled horizontally; the first column remains fixed.

- Rows where all elements are the same are grayed out—this makes the differences stand out.
- For numbers with a preference (“Higher is better” or “Lower is better”) and for ratings, the best value is highlighted in color and marked as “Best Value.”
- A **gallery** displays one or more images for each element. Readers can scroll through using the arrows; the frame button in the upper right enlarges the image to fill the screen. The gallery does not compare anything.
- If desired, there is a **Only Differences** toggle above the table that hides identical rows.

## What You See in the CMS Editor

The configuration dialog opens a large editing window: on the left are the elements, in the middle are the values of the selected element, and on the right are the dimensions, design, and behavior. Using the **Desktop**, **Tablet**, and **Mobile** options at the top of the window, you can view the table exactly as it appears on the page.
