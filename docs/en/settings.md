# Settings

## Dimensions (on the right, “Dimensions” tab)

| Setting | Description |
| --- | --- |
| Name | Appears in the first column. Required. |
| Type | **Text** (free-form text, line breaks preserved), **Number** (with unit, best value if desired), **Yes/No** (checkmark or X), **List** (one entry per line, as a bulleted list), **Selection** (one value from fixed options), **Rating** (1–5 stars), **Gallery** (images to browse and enlarge; does not compare anything). Default: Text. |
| Explanation | Optional; appears in small text below the name. |
| Unit | Only for numbers. Appears after each number, e.g., “PS” or “%”. |
| Best value | Only for numbers: **Neutral** (no mark), **Higher is better** or **Lower is better**. Default: Neutral. Ratings are always considered “higher is better.” |
| Options | Only for selection fields. The values from which each element allows a selection. At least one. |

## Elements (left and center)

| Setting | Description |
| --- | --- |
| Name | Appears above the column. Required. |
| Subtitle | Optional; appears one line below the name. |
| Values | One field per dimension, depending on the type. Blank means “not specified” and appears as “–”. |

Maximum of 12 elements, 60 dimensions, and 20 images per gallery.

## Design (right, “Design” tab)

| Setting | Description |
| --- | --- |
| Heading | Optional; appears above the table. |
| Accent | **Red**, **Charcoal**, or **Blue**—color of the line above the table, the checkmarks, stars, and top scores. Default: Red. |
| Hide identical rows | Rows in which all elements have the same value are grayed out. “Not specified” counts as a separate value. Galleries are never grayed out. Default: on. |
| Highlight Best Values | Highlights the best value for numbers with a preference and for ratings. If all elements have the same value, nothing is highlighted. Default: on. |

## Behavior (right, “Behavior” tab)

| Setting | Description |
| --- | --- |
| “Differences Only” toggle | Displays a toggle above the table that hides rows with no differences. The selection is not saved. Default: off. |
